# SkyLens India · NDD Mumbai

App sales + dashboard SkyLens untuk India (fork SkyLens 2.0 lewat SkyLens Việt Nam). Repo ini **hanya kode**.

- Halaman: https://digitalizationpma.github.io/SkyLens-India/ (dashboard di `dash/`, app sales di `app/`)
- Backend: Supabase "SkyLens India" (`ykugzswjdjwuakokidkg`). Data toko & petak disimpan privat di server, diunggah lewat dashboard Super Admin.
- Nama sales asli tidak ada di repo; app & dashboard membacanya dari server (RPC `roster_depo`).
- Isi data terbuka: jalan Overture Maps 2026-10-21.0 (`app/data/jalan/`) dan data uji karangan (`TESTING`).
- Bahasa: English (bawaan), हिन्दी, मराठी, Bahasa Indonesia.
- APK: repo privat `skylens-india-android` (OTA tampilan dari `app/ui.json`).
